# MarginMenu

A native macOS menu bar calculator for cost, revenue, and gross margin. Enter two values and adjust the result using sliders.

## Download

[Download the latest notarized installer](https://github.com/scripsweave/marginmenu-releases/releases/latest/download/MarginMenu.dmg)

Requires **macOS 26 or newer**. Supports **Apple silicon and Intel**.

Open the DMG and drag MarginMenu into Applications. Release assets include the notarized DMG, a ZIP containing the stapled app, SHA-256 checksums, and Apple's notarization result.

## Updates

Choose **… → Check for Updates…** in MarginMenu. Version 0.2.1 and later check this public repository automatically once a day while running, and after installing a new build. No account or token is needed. Downloads and installation remain manual.

[Public update feed](https://api.github.com/repos/scripsweave/marginmenu-releases/releases/latest)

This repository contains download information and release assets only. Application source code and development history remain private. Each release identifies its source build without including source files.
